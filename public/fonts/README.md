# Bundled interface font

VT323 Regular by Peter Hull, bundled unmodified from
https://github.com/google/fonts/tree/main/ofl/vt323 on 2026-10-27.
The SIL Open Font License is included in OFL.txt. The game loads the font
locally; it makes no font-service requests. VT323 supplies a home-computer
terminal appearance, rather than claiming exact Amiga or C64 hardware fidelity.
