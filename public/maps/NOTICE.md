# Map data notice

The maps in this folder (`cerea.json`, `cerea-outskirts/`, `lower-verona/` and their tiles) contain
information from **OpenStreetMap**, © OpenStreetMap contributors, made available under the
**Open Database License (ODbL) 1.0**: https://opendatacommons.org/licenses/odbl/1-0/
(see https://www.openstreetmap.org/copyright).

These maps are derived databases: the source extracts, the town and region specs and the tools that build
them are published in the game's source repository (`data/sources/`, `towns/`, `regions/`, `tools/`), and
the derived map data is offered under the same ODbL 1.0 terms. Building heights, colours, stopping bays,
signs, passenger names, fares and the shortened roads between towns are game interpretations, not claims
about the real places.

`harbor.json` is original handmade content and contains no OpenStreetMap data.
