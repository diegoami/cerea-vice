# Cerea Vice 0.14.0-rc.1

Release candidate for Windows x64: **the screens stop naming keys**. The briefing, driving, fare
list, pause and atlas screens describe what you can do, and every key and controller button is
listed in one place, **Change controls**. Turning atlas pages now keeps your zoom. It is a portable
playtest build; owner gameplay, Windows performance and physical controller checks are still pending.

## Play

Download the Windows ZIP, extract the entire folder to a local Windows drive, and open
**cerea-vice.exe**. Keep all the extracted files together. Node.js, npm, a server and an internet
connection are not needed to play.

This development build is unsigned and has no installer or automatic updater. Windows may display an
unknown-publisher prompt. Check the supplied SHA-256 checksums before running a downloaded copy.

## Changes since 0.13.0-rc.3

### Key and button names only under Change controls (#93)

- **Playing screens no longer list bindings.** Gone are:
  - the controls table on the briefing and pause screens;
  - the "A / ENTER TO …" button notes;
  - "ESC / START PAUSE" on the dashboard;
  - the key suffixes and footer of the fare list;
  - the atlas footer and tool-button hints;
  - the keys in the stopped-car prompt and in road hints such as "then press T".
- **Screens describe actions instead**, e.g. "Collect Elena · Ask for information · Atlas · Select
  reverse", or "Come to a complete stop before opening the atlas."
- **Change controls is the one place for mappings.** It keeps the remappable driving bindings and
  adds a read-only **Fixed controls** list for the main screen, fare list, atlas and its index, menus,
  looking around and pause. Atlas actions that follow a remappable binding show your current choice.
  The briefing and pause screens point there in one line.
- **The atlas footer** now carries the map attribution beside *Close atlas*, leaving the map one more
  row.
- **The first hint of a shift** is the shift's own notice ("Free driving. Stop and request fares.").
  It is no longer Cerea's old map hint, which named a key and a first passenger who no longer exists.

No input changed: every key and button works as before, and remapped bindings still apply
everywhere.

### Atlas

- **Turning between detail pages keeps the zoom** (#104).
  - A neighbouring page continues from the ground you were reading; pages overlap at their edges.
  - A distant page keeps your place on the page.
  - At 100% a turn still shows the whole page. A page opened from the overview starts at 100%.
  - Street lookup still focuses at 5×.

There is still no GPS, minimap, route line, objective arrow or live atlas marker. Page turns, zoom
and pan never move the position marker, and reading still pauses the clock.

### Release tooling

- The lock file now carries the package version, and a release test fails if they differ. 0.13.0-rc.3
  could not be packaged at its reviewed commit for this reason (#106).

## Saves and settings

Windows player data is in `%LOCALAPPDATA%\CereaVice\profile`.

- **Saves from 0.13.0-rc.3 still load**: no map data changed, and the save format is unchanged.
  Settings and control profiles are kept.

## Playtest focus

- Without keys on screen, is the game still easy to pick up? Can a new player find Change controls
  from the briefing or pause screen, and is the Fixed controls list easy to read with a controller?
- Do the stopped-car prompt and road hints still make clear what is possible at a stop?
- Atlas: zoom in, turn to a neighbouring page. Does the view continue where you expect?
- Still open from earlier playtests: highlight the current journey target in the index (#87),
  town-name direction signs between towns (#84), return to the main screen from the pause menu (#85).

Not verified in this candidate: Windows performance and memory (measured only under a software
renderer on Linux), the WSL launcher on the Windows host, and physical controllers.
