# Cerea Vice 0.8.0-rc.2

Release candidate for Windows x64, covering the 0.7 presentation/control and
0.8 taxi-shift milestones. It is a portable playtest build; owner gameplay and
physical controller testing are still pending.

## Play

Download the Windows ZIP, extract the entire folder to a local Windows drive,
and open **cerea-vice.exe**. Keep all the extracted files together. Node.js,
npm, a server and an internet connection are not needed to play.

The briefing offers **Cerea Centro**, **Harbor District**, and **Cerea outskirts
prototype**. The outskirts district connects real Cerea to a clearly labelled
fictional test hamlet. Choose the district before starting.

This development build is unsigned and has no installer or automatic updater.
Windows may display an unknown-publisher prompt. Check the supplied SHA-256
checksums before running a downloaded copy.

## Review corrections since rc.1

- Enter, Escape and P resume from settings action buttons, including after a
  mouse save/load. Space activates a keyboard-focused settings action.
- Dispatch radio messages show the same guaranteed payment as the quoted offer,
  including the long-collection supplement and pending offers loaded from rc.1.
  Completed-fare payout feedback is retained when the next offer is quoted.
- Only B / Backspace declines a fare; X / Square and Delete no longer discard it.
- Validation counts now include the release/archive and new regression checks.

Rc.1 remains a draft at its original reviewed commit. This candidate contains
review fixes and requires an independent recheck before promotion.

## Changes

- Larger, consistent retro text across the HUD, atlas, menus and settings, with
  a locally bundled font and no font-service requests.
- Clothed, faceted people. A collected passenger leaves the pavement and sits
  beside you; look right to see them. Dropoff clears the seat.
- Random pickup/destination pairs on new shifts, including both directions of
  the hamlet journey. Offers show the pickup, destination and guaranteed pay.
- Accept with **A / Enter**, or decline with **B / Backspace**. Reading an offer
  pauses the shift. **Start / Escape** opens the pause/save menu.
- Long journeys pay more even after their speed bonus expires. Municipio to
  the hamlet guarantees €37.94; the directed return guarantees €43.41, before
  any long-collection supplement and up to €6 of speed bonus.
- **Change controls** in the briefing/pause menu remaps driving keys and
  controller buttons. B remains the default gear control; L3 is selectable.
  Restore defaults and the fixed menu/atlas controls remain available.
- **Save shift / Continue saved shift** retains the car, gear, time, earnings,
  passenger/offer and atlas knowledge. Continue loads paused. There is one
  manual slot per district; starting a new shift keeps the previous save until
  you explicitly save again.

The compass still shows car heading. There is no GPS, minimap, route line or
live atlas marker. Information requests and deliberate estimates remain the
only ways to change your atlas position knowledge during a shift.

## Saves and upgrades

Windows player data is in `%LOCALAPPDATA%\CereaVice\profile`. Both portable
copies and the WSL playtest launcher use this location. Closing the game or
replacing its application folder keeps saves and control/presentation settings.
Close the old copy before launching an upgrade, and keep the player profile.

There is no save migration from the earlier disposable 0.6.1 playtest profiles.
The interim implementation's persistent profile uses the same save format and
map signature as this candidate. Changed maps or future incompatible save
formats are reported when loading; the stored save is retained.

## Playtest focus

Text readability at normal viewing distance, the passenger view, L3 comfort,
the accept/decline loop, long-trip balance, and Save → close → relaunch →
Continue on Windows need owner testing. Controller automation uses a simulated
standard gamepad and cannot establish physical comfort. Passenger boarding and
departure are state changes; walking animations are not included.

The independent review of rc.1 is recorded on that PR; these corrections await
