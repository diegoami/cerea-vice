# Cerea Vice 0.13.0-rc.3

Release candidate for Windows x64: **the atlas becomes a book**. Large and dense districts are read
through overlapping printed pages instead of one crowded sheet, zoomed-out paper shows the major-road
network, and the grid references stay readable while you zoom. It collects the atlas work played and
reported by the owner after 0.13.0-rc.2. It is a portable playtest build; owner gameplay, Windows
performance and physical controller checks are still pending.

## Play

Download the Windows ZIP, extract the entire folder to a local Windows drive, and open
**cerea-vice.exe**. Keep all the extracted files together. Node.js, npm, a server and an internet
connection are not needed to play.

This development build is unsigned and has no installer or automatic updater. Windows may display an
unknown-publisher prompt. Check the supplied SHA-256 checksums before running a downloaded copy.

## Changes since 0.13.0-rc.2

### The atlas book

- **Large districts use local quadrants**: the Lower Veronese plain is a book of fixed 1.2 km pages
  with 200 m of overlap, a regional overview, north/south/east/west links between neighbouring pages,
  and page + local-grid references in both indexes. The original Cerea town fits one page (#92).
- **Verona centro receives 25 detail pages** chosen by street density rather than district size: a
  compact dense town now gets smaller, unequal pages (360–571 m) so no page carries more street labels
  than the busiest accepted regional page. The dense medieval centre gets the smallest pages. Cerea,
  the outskirts prototype and Harbor keep their single sheets (#89).
- **Zoomed-out paper prints only the major network**: primary, secondary and tertiary roads (and
  classless roads on authored maps) print at every scale; residential and pedestrian streets appear
  from 2× zoom; service roads, paths and steps appear from 4×. Street labels follow the same rule, a
  street lookup still focuses at 5× with everything printed, and the major network draws on top at
  crossings (#88). **This changes the 1× look of every district, including Cerea**: zoom in to see
  residential streets.
- **Grid references stay readable while zoomed** (#86): the A–D / 1–4 edge labels clamp into the view
  when the paper edges scroll off, and a small reference beside the zoom level shows the printed page
  and cell under the view centre. It describes the paper being read — never the car.
- The desktop package includes every district helper, fixing a packaged-startup failure found during
  this work (#92).
- Directions received in the atlas stay visible on the map page in shorter and narrower windows
  (#103): on a 1366×768 laptop the detail-page atlas used to hide the received information and the
  key, and windows 761–1050 px wide hid the information in every district. Short windows now keep a
  compact margin with information and key; mid-width windows keep the information column.

There is still no GPS, minimap, route line, objective arrow or live atlas marker. Page selection,
lookup, zoom and pan never move the position marker; reading still pauses the clock; the marker
changes only after a successful information request or your own estimate.

### Test infrastructure

- Two desktop smoke timeout caps doubled (Cerea atlas run 90 s → 240 s, text-fit sweep 180 s → 360 s):
  software-rendered machines needed 115 s and 172 s, so real passes flaked (#99). No product change.

## Saves and settings

Windows player data is in `%LOCALAPPDATA%\CereaVice\profile`.

- **Saves from 0.13.0-rc.2 still load**: no map data changed in this candidate, and atlas knowledge
  (marker and its source) is unchanged. Settings and control profiles are kept.

## Playtest focus

- Verona: find every fare pickup and destination from the index — page reference, open quadrant,
  locate at 5×. Is 25 pages the right amount, and are page links clear at the edges?
- Zoomed-out readability: is the major-road network enough to understand where towns connect, at
  regional scale and on Cerea's own sheet at 1×?
- The view-reference chip while zoomed: does it answer "where on the page am I?" without clutter?
- Known outstanding atlas and playtest work, planned next: highlight the current journey target in
  the index (#87), town-name direction signs between towns (#84), return to the main screen from the
  pause menu (#85), device-specific control prompts (#90) and removing mapping explanations from the
  playing screens (#93).

Not verified in this candidate: Windows performance and memory (measured only under a software
renderer on Linux), the WSL launcher on the Windows host, and physical controllers.
