# Cerea Vice 0.12.0-rc.1

Release candidate for Windows x64: the villages between the lower-plain towns, and the follow-ups from the
0.11 milestone review. It is a portable playtest build; owner gameplay, Windows performance and physical
controller checks are still pending.

## Play

Download the Windows ZIP, extract the entire folder to a local Windows drive, and open
**cerea-vice.exe**. Keep all the extracted files together. Node.js, npm, a server and an internet
connection are not needed to play.

This development build is unsigned and has no installer or automatic updater. Windows may display an
unknown-publisher prompt. Check the supplied SHA-256 checksums before running a downloaded copy.

## Changes since 0.11.0-rc.1

### Villages between the towns (Lower Veronese plain)

- The roads between the six towns now pass through the real streets and buildings of seven villages and
  hamlets: **San Pietro di Legnago, Concamarise, Aselogna, Venera, Belfiore, Alberoni and Casella**. They
  are at real scale, have no stops, and are labelled in the atlas.
- Crosare, Malcanton, Magarino and Dossi are not included: they sit right next to a town (or to Venera),
  and with the roads between towns shortened their areas would overlap.
- Drive times are unchanged within a few seconds (Cerea–Legnago about 5 minutes at 60 km/h).

### Review follow-ups

- **Saves at any speed:** with Top speed set to No limit, a shift can be saved at any speed the car
  reaches (0.11 refused saves above 400 m/s).
- **District list safety:** district names and attributions must be plain text and are escaped where
  they are shown, ready for town folders loaded at runtime later.
- **WSL launcher:** `node desktop/run-windows.mjs lower-verona` (and any registered district) works.
- **Region tooling:** the region spec states the zone margin it uses, the builder rejects settings it
  would ignore, town builds are redone whenever their spec or data changes, and the shipped region is
  checked field by field against a fresh build.
- `docs/TOWNS.md` describes the code as it is.

There is still no GPS, minimap, route line, objective arrow or live atlas marker.

## Saves and settings

Windows player data is in `%LOCALAPPDATA%\CereaVice\profile`.

- **Lower Veronese plain saves from 0.11 no longer load** (map data version 2, since the villages change
  the map). The game names both versions and keeps the old save; start a new shift there.
- Cerea Centro, outskirts and Harbor saves from 0.11 still load. Settings and control profiles are kept.

## Playtest focus

- Driving through the villages: do they read as places on the way, and do the roads join their streets
  cleanly?
- The region's load time, smoothness and memory on Windows (5.3 MB of map data plus 1,760 tiles).

Not verified in this candidate: Windows performance and memory for the region (measured only under a
software renderer on Linux), the WSL launcher on the Windows host, and physical controllers.
