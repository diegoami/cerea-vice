# Unreleased: quieter driving HUD

The upper-left header now shows the current pickup or destination as landmark,
town and street. The world banner and duplicate objective card are removed.
Earned money is a counter beside the clock; fare counts and the current base/bonus
remain available in its hover/accessibility description and the requested mission reminder.

Automatic taxi-radio messages last briefly at stops and disappear while moving.
Requested information/directions remain available, and ordinary stopped controls
appear only when stopped. The demo label is exactly `DEMO  MODE`, without activity
text. Maps, saves, navigation knowledge and driving rules are unchanged.
